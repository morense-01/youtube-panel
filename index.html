Bienvenido a tu Panel YouTube

Para empezar, necesitas tu clave de API de YouTube (gratis). Tu clave solo se guarda en este navegador.

¿Cómo creo mi API key?
  1. Entra a console.cloud.google.com.
  2. Crea un proyecto (o selecciona uno) y abre el menú "APIs y servicios".
  3. Activa YouTube Data API v3.
  4. Ve a "Credenciales" → "Crear credenciales" → "Clave de API".
  5. Copia la clave y pégala aquí. Recomendado: restríngela a "Apps HTTP" con tu dominio de GitHub Pages.
